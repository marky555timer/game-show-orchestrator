Drop your medley sweepers here (short .wav or .mp3 one-shots: whooshes, "DJ"
drops, risers). They play every few transitions during Dance Medley mode
(config.MEDLEY_SWEEPER_EVERY).

Sweeper mode (config.MEDLEY_SWEEPER_MODE_DEFAULT / the web remote):
  off    - no sweepers in a medley
  medley - only files in THIS folder
  all    - this folder plus the regular audio/sweepers folder
Announcements are always off during a medley.
