Administrator

Stop the show? This ends the current game immediately in front of the room -- only do this if something's actually gone wrong.

Shut down the Game Show Orchestrator app on the host machine? This ends the show and can only be undone by relaunching it there.

Power off the Raspberry Pi itself, not just this app? Everything stops -- DMX, LEDs, audio, this web remote, all of it. To turn it back on, press the button on the outside of the box (or unplug/replug power).
