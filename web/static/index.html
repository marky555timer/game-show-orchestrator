Application

Administrator

Stop the show? This ends the current game immediately in front of the room -- only do this if something's actually gone wrong.

Restart the Game Show Orchestrator app? This briefly interrupts the show (DMX blackout, audio stop) and relaunches automatically -- expect it back within a few seconds.

Power off the Raspberry Pi itself, not just this app? Everything stops -- DMX, LEDs, audio, this web remote, all of it. To turn it back on, press the button on the outside of the box (or unplug/replug power).

Reboot the Raspberry Pi itself, not just this app? Everything stops and the whole Pi restarts on its own -- DMX, LEDs, audio, this web remote, all of it comes back up automatically after. Expect a minute or two of downtime.
